# Local typefaces

Google Fonts full TrueType distributions, including Vietnamese and Latin Extended glyphs:

- Be Vietnam Pro: 400, 500, 600, 700.
- Montserrat: 800.

`fonts.css` uses `font-display: swap`. All files load from this directory, including when external requests fail. Fontconfig inspection confirmed `vi` coverage in each file. Font families and weights are also checked in the browser proof.

Source: [Google Fonts CSS API](https://fonts.googleapis.com/css2?family=Montserrat:wght@800&family=Be+Vietnam+Pro:wght@400;500;600;700&display=swap&subset=vietnamese,latin-ext).
